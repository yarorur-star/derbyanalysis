# derbyanalysis
в файле pp_ddl.sql ddl-структура базы данных derby embedded с описанием контента в комментариях
база данных по торговле рыбными товарами ФАО 
в папке /CSV лежат .csv дампы таблиц этой базы данных, включая основную таблицу с данными TSD_TRADE_PP_QUANTITY, остальные таблицы либо описательные списки REF_ либо реляционные REL_
если поле не описано комментарием оно не имеет никакого значения и игноируется 
в базе много полей с именованиями на языке отличном от английского - они игноруются, используются только поля _EN
